# Roadmap

**Canonical index:** [00_index.md](00_index.md)

## Purpose

This file tracks the next product directions, not a detailed delivery plan.

## Current focus

- keep sync stable;
- keep Telegram output readable;
- keep admin tables compact and searchable;
- keep billing and reminders reliable;
- keep documents short and canonical.

## Near-term priorities

1. Improve operator workflows.
2. Reduce false notifications.
3. Support more filters in subscriptions.
4. Keep the UI compact on mobile and desktop.
5. Add new sources only when the model supports them cleanly.

## Product direction

- SaaS for real-estate monitoring;
- multiple subscription tiers;
- better filtering and routing;
- more sources over time;
- stronger operational visibility.

## Rule

If a feature is not needed for the current business flow, keep it out of the main path.
